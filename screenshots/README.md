# Screenshots

The images in this directory show dashboard demo data:

- `overview.png`: overview.
- `efficiency.png`: efficiency analysis.
- `token-usage.png`: input and output token usage.
- `daily-credits.png`: daily credit trend.
- `cache-ratio.png`: cache read ratio.
- `agent-model.png`: credits by agent and model.
- `agent-credits.png`: credits by agent.

Files with a `-tr` suffix show the same views in Turkish.

When updating screenshots, select the **Demo data** source. Check that they
contain no real session information, file paths, or sensitive data.
